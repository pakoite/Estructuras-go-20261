# ⛩️ Lineamientos Generales: Tareas, Prácticas y Exámenes

🌕 🌖 🌗 🌘 🌑 🌒 🌓 🌔

## 🌱 Objetivo
Evaluar la comprensión de los temas vistos en clase mediante la implementación de soluciones en código, aplicando lógica, estructuras y buenas prácticas.

---

## 🤖 Requisitos generales

### 🔹 Implementación
- Resolver el problema planteado en cada actividad
- Usar correctamente estructuras de datos (`struct`, slices, maps, etc.)
- Aplicar lógica clara y ordenada

---

### 🔹 Código
- El programa debe compilar y ejecutarse sin errores
- Debe cumplir con los requerimientos solicitados
- Debe estar organizado y ser legible

---

### 🔹 Entrega
- Archivo `.go` o repositorio
- Nombre claro del archivo o proyecto " **matricula-nombreArchivo.go** "
- Entrega en la fecha indicada

---

## 💻 Uso de herramientas
- Puedes usar herramientas de apoyo (incluyendo IA)
- Debes comprender completamente tu código
- Debes ser capaz de explicarlo

---

## 👀 Criterios de evaluación

- **30%** Uso correcto de estructuras  
- **30%** Lógica del programa  
- **20%** Funcionamiento  
- **10%** Claridad del código  
- **10%** Explicación (defensa)  

---

## 🔥 Evaluación en clase
Durante la evaluación se podrá:

- Solicitar explicación del código
- Pedir modificaciones en tiempo real
- Realizar preguntas sobre la implementación

---

## 🦾 Puntos extra (opcional)
- Mejoras funcionales
- Código más eficiente
- Implementación de características adicionales

---

## 🍁 Restricciones
- No copiar código sin entenderlo
- No entregar código que no puedas explicar
- No compartir soluciones entre compañeros

---

## 🧨 Importante
Si no puedes explicar tu código o realizar modificaciones básicas, la actividad se considerará como **no acreditada**, aunque el programa funcione.
